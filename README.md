🧠 Advice Generator

Este é um aplicativo simples e estiloso que gera conselhos aleatórios com apenas um clique. Ideal para quem quer um toque de sabedoria no meio do dia.  

🔗 Acesse o projeto  
🔮 Clique aqui para ver o app funcionando

✨ Funcionalidades

- Gera conselhos aleatórios com base na [API Advice Slip](https://api.adviceslip.com/).
- Layout moderno e responsivo.
- Animações suaves e interface intuitiva.

🛠️ Tecnologias utilizadas

- HTML5

- JavaScript

🚀 Como rodar localmente

Clone o repositório:
   git clone https://github.com/GERINALD0/advice-generator.git
   
Acesse a pasta do projeto:
  Abra o arquivo index.html no navegador (pode arrastar e soltar no navegador ou usar uma extensão como Live Server).
